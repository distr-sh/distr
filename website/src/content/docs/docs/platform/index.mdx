The Distr Distribution Platform covers the commercial and operational side of shipping software into customer-controlled environments: what you ship, who is allowed to run it, what their license permits and what you can see once it runs.

## Platform Capabilities

- **Application delivery**: define Docker Compose and Helm applications with versions and configuration templates, then roll them out and track every revision. See [Application](/docs/agents/application/) and [Deployment](/docs/agents/deployment/).
- **Docker and Kubernetes deployment agents**: the [Docker agent](/docs/agents/docker-agent/) runs Compose projects on any Linux host and supports Docker Swarm, and the [Kubernetes agent](/docs/agents/kubernetes-agent/) manages Helm releases with cluster- or namespace-scoped permissions. See [Deployment Agents](/docs/agents/).
- **Customer management**: create customer organizations, invite their users and turn portal features on per customer. See [Customer Management](/docs/platform/customer-management/) and the white-labeled [Customer Portal](/docs/platform/customer-portal/).
- **Application and artifact entitlements**: control which application versions a customer may deploy and which artifacts and tags they may pull. See [Application Entitlements](/docs/platform/application-entitlements/) and [Artifact Entitlements](/docs/platform/artifact-entitlements/).
- **Signed offline license keys**: issue Ed25519-signed JWTs carrying your own claims, verified locally by your application without a callback to Distr, so licensing also works in air-gapped environments. See [License Keys](/docs/platform/license-keys/).
- **Logs, metrics and support bundles**: follow deployment status, agent and container logs and host metrics, and let customers hand over diagnostics when they report an issue. See [Logs & Metrics](/docs/agents/logs-and-metrics/) and [Support Bundles](/docs/platform/support-bundles/).
- **Cloud and self-hosted operation**: run on Distr Cloud or operate the platform yourself with Docker Compose or Helm. See [Self-Hosting](/docs/self-hosting/).
