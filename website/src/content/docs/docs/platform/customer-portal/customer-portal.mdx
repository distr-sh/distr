The Customer Portal is a simplified, white-labeled UI built for end customers. Vendors control which sections each customer can access through [Customer Management](/docs/platform/customer-management/#enabling-and-disabling-features-per-customer).

## Portal sections

The sidebar shows the sections that are enabled for your organization. A fully configured portal includes:

| Section                                                        | Description                                                                                                                             | Visibility                                  |
| -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| **Home**                                                       | Deployments, license, activity, a getting started checklist and your vendor's instructions                                              | Always visible                              |
| **[Deployments](/docs/platform/customer-portal/deployments/)** | Deploy and manage controllers and applications                                                                                          | On by default                               |
| **[Artifacts](/docs/platform/customer-portal/registry/)**      | Browse and pull software artifacts from the registry                                                                                    | On by default                               |
| **[Licenses](/docs/platform/customer-portal/licenses/)**       | View license keys and tokens issued by your vendor                                                                                      | Once your vendor has issued a license key   |
| **Notifications**                                              | Configure [alerts](/docs/controllers/alerts/) and [update notifications](/docs/controllers/update-notifications/) for your organization | Off by default                              |
| **[Support](/docs/platform/customer-portal/support/)**         | Create and manage support requests and bundles for troubleshooting                                                                      | Off by default                              |
| **Security**                                                   | Read the [security advisories](/docs/platform/vulnerability-management/) your vendor publishes                                          | On by default with Vulnerability Management |
| **Team**                                                       | Manage users in your organization                                                                                                       | Admins only                                 |
| **[Secrets](/docs/platform/customer-portal/secrets/)**         | Store and manage deployment secrets                                                                                                     | With Deployments                            |
| **Settings**                                                   | Choose the controller image repository and connect your own identity provider                                                           | Admins only, off by default                 |

**Deployments** and **Artifacts** are enabled by default for new customers. **Alerts**, **Update Notifications**, **Support** and **Advanced Settings** must be explicitly enabled by the vendor. Disabled sections are hidden entirely from the Customer Portal, so customers only see what has been enabled for them.

In addition to these sections, vendors can configure [links](/docs/platform/customer-management/#managing-links-per-customer) per customer, for example to documentation or a support page. They are shown at the bottom of the sidebar and open in a new tab.

Vendors manage these settings under **Customers** in the Vendor Portal. See [Enabling and disabling features per customer](/docs/platform/customer-management/#enabling-and-disabling-features-per-customer) for details.

<Aside type="note">
  If a section is missing from your portal, contact your vendor to request
  access.
</Aside>

## Access Tokens

In the top-right user menu, open **Personal Access Tokens** to generate [Personal Access Tokens (PATs)](/docs/integrations/personal-access-token/). PATs are required for authenticating with the artifact registry.
