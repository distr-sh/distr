Distr works with your existing development workflow and tools. Use the APIs, SDKs, and platform integrations to automate your software distribution pipeline.

## CI/CD Integrations

Automate your deployment pipeline with native integrations:

- **[Automatic Deployments from GitHub](/docs/integrations/github-actions/)** - Step-by-step guide to set up automatic deployments from your GitHub workflows
- **[GitHub Action Reference](/docs/integrations/gh-action/)** - Complete reference for the distr-create-version-action

## Air-Gapped Delivery

Deliver your application into disconnected and air-gapped environments:

- **[Air-Gapped Deployments with Zarf](/docs/integrations/zarf/)** - Package your Helm chart and all container images into a single Zarf package and distribute it through the Distr registry

## Kubernetes Cluster Setup

Serve a Helm application to customers that operate no Kubernetes cluster:

- **[Cluster Setup with k3s](/docs/integrations/k3s/)** - Install k3s on the customer's Linux server with the connect command, provision a managed cluster in their cloud account or install k3s offline with Zarf

## Amazon Elastic Container Service (ECS)

Run your application on the ECS clusters your customers operate in their own AWS accounts:

- **[Deploying to Amazon ECS](/docs/integrations/aws-ecs/)** - Pull your images from the Distr registry into ECS tasks, with registry credentials, secrets and configuration kept in the customer's AWS account

## API & SDKs

Access Distr programmatically using our REST API and client libraries:

- **[Distr API](/docs/integrations/api/)** - REST API for managing applications, deployments, and customers
- **[API Reference](https://app.distr.sh/docs)** - Interactive API documentation
- **[JavaScript/TypeScript SDK](/docs/integrations/sdk/)** - Official SDK for Node.js and TypeScript applications
- **[Personal Access Tokens](/docs/integrations/personal-access-token/)** - Generate API tokens for authentication
