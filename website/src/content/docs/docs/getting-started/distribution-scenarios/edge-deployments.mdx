Edge Deployments let vendors manage software in decentralized, often resource-constrained environments that operate outside traditional data centers.
In this model, vendors maintain control of both the software and the deployment target, whether IoT devices, custom hardware or edge infrastructure.
The Distr controllers are lightweight and add little to no overhead to edge IoT devices, which often have limited resources.
