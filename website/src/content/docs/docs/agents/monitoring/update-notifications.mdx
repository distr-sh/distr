Update notifications tell selected users by email that a new version is available: a new version of an application whose deployments are still on an older one, or a new version of an artifact in the registry.

<Aside type="note">
  Update notifications are a **Pro feature** and require a [Pro
  subscription](/pricing/).
</Aside>

## How to Configure Update Notifications

In the sidebar, navigate to **Notifications** > **Updates**, where applications and artifacts each have their own tab.

1. Click **Create Notification**.
2. Enter a name for the configuration.
3. Select the applications or artifacts to watch.
4. Select the users who should receive the emails. Your own team, your partners and your customers' users can all be picked.
5. Optionally, write a message that is included in every email this configuration sends, for example a link to the changelog or an upgrade instruction.

Each configuration can be toggled on or off without deleting it, and the **History** page lists what has been sent.

## When a Notification Is Sent

An application notification is sent when a new version of a watched application is created, to every selected recipient who can see at least one deployment that does not run it yet. A customer is left out while their [entitlement](/docs/platform/license-management/) does not cover the new version, and hears about it once the entitlement is widened.

An artifact notification is sent when a new tag is pushed to a watched artifact. Artifacts that mirror an upstream registry cannot be watched, because all of their versions appear at once when the mirror syncs.

Each recipient hears about a version once per configuration, however many deployments are affected.

## Notification Emails

Every email contains the application or artifact, its type and logo, the new version, the message of the configuration when one is set, and a link to Distr.

A recipient from your own team or a partner organization sees every affected customer and deployment in one email. A customer user sees only their own deployments.
