| Data                                                                                                                                                                                                      | When                                                                                 |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| Controller logs at debug level, including connection events, reconciliation cycles, errors and the output of Docker and Helm operations                                                                   | Always                                                                               |
| The status of every deployment, whose message can contain the Compose progress, the Helm output, image names and error output                                                                             | Always                                                                               |
| stdout and stderr of the containers of the deployments                                                                                                                                                    | When [log collection](/docs/controllers/logs-and-metrics/#container-logs) is enabled |
| Docker: CPU, memory and disk usage of the host with the device names and mount paths, the size of the image store and the CPU, memory, limits and log size of every container of the deployments          | When [metrics](/docs/controllers/logs-and-metrics/#metrics) are enabled              |
| Kubernetes: CPU and memory capacity and usage summed over all nodes, the usage of the controller pod and the CPU, memory and limits of every container of the deployments with its pod and workload names | When [metrics](/docs/controllers/logs-and-metrics/#metrics) are enabled              |

The controller reads no logs or metrics of containers outside its deployments apart from its own. Distr masks the secrets of the deployment target and common credential patterns in logs before it stores them, see [Log Redaction](/docs/controllers/secrets/#log-redaction). Status messages are stored as reported.

Log collection and metrics are settings of the deployment target, see the [Configuration Reference](/docs/controllers/security/configuration/).

## Example Controller Logs

These lines are taken from the controller logs of a Kubernetes and a Docker deployment target, as Distr shows and exports them. Every line has the time, the level, the place in the controller's code, the message and the fields of the message. Lines written by Helm carry `"component": "helm"` instead of a place in the code. The container logs of the deployments are not part of the controller logs.
