Controller Registry

The registry controllers pull their images from. Distr appends the image names docker-controller, kubernetes-controller and docker-autoheal with the controller version as the tag, so a mirror has to host them under the same names.

A registry host followed by an optional path, e.g. {{ exampleRegistry() }} for your Distr registry. Save it empty to pull from {{ state.defaultImageRegistry }}. A change applies when a deployment target connects and at its next controller update.

The controller images have to be publicly available in this registry, or every deployment target needs access to it before you save.
